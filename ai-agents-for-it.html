Questions, answered

What can an AI agent do for IT?

Triage issues, draft PR review notes and write runbooks. In Orchy, any change or delete waits for your approval.

Does it merge code or change systems on its own?

No. It drafts and suggests. Changes wait for a person's Approve.

Which IT tools does it work with?

GitHub, Slack and Notion, plus other apps available through One.
