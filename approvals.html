01

Five things it asks about

Sending. Money. Calendar. Deleting. Sharing. Before an agent does any of these, Orchy stops and asks you. Everything else, such as reading, drafting and taking notes, runs on its own.

02

You see it before it happens

When an agent wants to send, post, spend money, change a calendar, delete or share, an approval pop-up shows what it wants to do and why it asks. Approve it, or deny it.

  • Approve onceThis action
  • Always allowOne agent
  • Always allowEvery agent here
  • Gmail forwarding or filterEvery time
03

Approve once, or always allow

Some actions you will want to approve every time. Others you trust an agent with. Approve a single action, or choose "Always allow" for one agent or for every agent in the workspace, one action at a time. You can also switch each type of approval off in Settings.

Some asks always come back, and handed-over tasks never offer "Always allow". A change to Gmail forwarding or a Gmail filter asks every time, with no "always allow".

  •  Inbox agent · GmailRead
  •  Social agent · LinkedInFull
  • App outside its listAsks first
04

Give agents only the access they need

Every app an agent can use is set to read or full access. An agent with read access can look things up and can't change anything. Orchy checks each app call against the workspace's and the agent's connections before it runs, and asks you if an agent reaches for an app outside its list.

05

A record of every task

See what an agent did, what it asked, and what you approved.

06

Approvals work in every client workspace

Each client's workspace asks on its own. An "Always allow" covers one action in one workspace, for one agent or all its agents. It never carries over to another workspace.

Questions

FAQ

What does Orchy ask about?

By default it asks before it sends or posts, spends money, changes a calendar, deletes or shares. Reading, drafting and taking notes run on their own.

What happens if I deny?

You turn it down and the action doesn't run.

Can I skip the question for tasks I trust?

Yes, one action at a time. Choose "Always allow" for one agent or every agent in a workspace, or switch a type of approval off in Settings. Changes to Gmail forwarding and Gmail filters always ask.

Where can I see what was approved?

In the task record: what ran, what it asked, and what you approved.

Can an agent change things in an app I only gave it read access to?

No. Read access allows lookups only.
