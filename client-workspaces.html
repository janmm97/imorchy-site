Features/Client workspaces

One workspace for every client.

A separate AI workspace for each client you work for.

Each client gets their own apps, agents and files. A task runs in one workspace, so six clients in one day stay apart.

Apps, agents and files switch with the client. They never mix.

01

Clients don't share a pile

A single AI chat treats every client as one pile of tasks, accounts and files. Orchy gives each client a workspace of their own, so the work you do for one client stays with that client.

02

What sits inside a workspace

  • Their apps.

    Connect each client's accounts to that client's workspace only.

  • Their agents.

    Set up the agents each client needs, or ask the Agent Builder to write one. Every workspace also has a generalist for tasks no specialist fits.

  • Their files.

    Notes and files stay in the workspace they belong to.

  • Their memory.

    What Orchy remembers is looked up one workspace at a time.

03

A task runs in one workspace

Say the task inside the client's workspace. Orchy checks every app call against that workspace's connections. If an agent reaches for an app outside its list, Orchy asks you first, and accounts are never mixed between workspaces.

A job that takes several steps runs as a mission inside that one workspace. A mission never spans two clients.

04

Add a client. Switch one off.

Add a workspace when you take on a client. Switch it off when the work pauses: a switched-off workspace gets no tasks and no scheduled runs. Retire it when the work ends.

05

Approvals apply in every workspace

By default, each workspace asks before it sends or posts, spends money, changes a calendar, deletes or shares. You read what the agent wants to do and approve it or turn it down.

Questions

FAQ

Will Orchy mix up my clients?

Each client has a workspace with its own apps, agents and files, and a task runs in one workspace. Accounts are never mixed between workspaces.

Can one task touch two clients?

No. A task runs in one workspace, and a mission with several steps stays inside one workspace too.

What happens when I switch a workspace off?

It gets no new tasks and no scheduled runs until you switch it back on.

Which apps can I connect to a workspace?

Through One, Orchy can connect to 1,000+ apps. You connect the apps each client uses to that client's workspace.

Do approvals work the same in each workspace?

Yes. By default Orchy asks before it sends or posts, spends money, changes a calendar, deletes or shares, in every workspace.
