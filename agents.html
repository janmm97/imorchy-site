01

An agent is a job in plain words

You don't write code. An agent is a description of the job: what it does and which apps it may use. Say what you need done and Orchy picks the right agent for the task.

  •  GmailRead
  •  Google SheetsRead

02

The Agent Builder writes it for you

Tell the Agent Builder what the agent should do. It proposes the agent and picks the apps it needs, each at read or full access. You confirm the apps in a pop-up before anything is connected.

  •  Inbox agent · GmailFull
  •  Report agentRead

03

You choose each agent's apps and access

Every app an agent can use is set to read or full access. If an agent reaches for another app in the workspace, Orchy asks you first. Apps come through One, and you connect them per workspace.

04

Agents can run on a schedule

Ask for a job that repeats, such as a weekly client report, and the agent runs at the time you set. Scheduled agents still ask before they send or post, spend money, change a calendar, delete or share, unless you've switched that off.

05

Every agent asks first

By default an agent asks before it sends or posts, spends money, changes a calendar, deletes or shares, whoever built it. Choose "Always allow" for one agent or every agent in a workspace, one action at a time. Handed-over tasks never offer it.

06

A team for each client

Agents belong to a workspace. Each client gets the agents they need, and every workspace also has a generalist for tasks no specialist fits.

Questions

FAQ

Can I build my own agent?

Yes. Describe the job in plain words and the Agent Builder sets up the agent, with its apps and the actions it must ask about first.

Do I need to code?

No. You describe the job in plain words.

Which apps can an agent use?

The apps you connect to its workspace through One. You give each agent its apps at read or full access.

Can an agent act without asking me?

By default, not on the five things Orchy asks about: sending, money, calendar changes, deleting and sharing. You can switch each off in Settings. Reading, drafting and taking notes run on their own.

Can an agent work for more than one client?

Agents belong to one workspace, and a task runs in that workspace.

Which AI provider does it use?

You bring your own key from OpenRouter, Anthropic or OpenAI, and agents run on your account with that provider.
