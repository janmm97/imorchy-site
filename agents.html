Questions, answered

Do I need to code to build an AI agent?

No. Describe the job in plain words. The Agent Builder sets up the agent, its apps and its approvals.

How do I build an AI agent?

Sign in, open the Agent Builder, describe the job, pick its apps and save. The agent is ready for tasks.

Can I change what an agent can do?

Yes. You choose each agent's apps and access, and can change them any time.

Can AI agents run on a schedule?

Yes. Run an agent daily or weekly, like an inbox sort or a weekly report.

Hand off the work. Approve what goes out.
